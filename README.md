# 🌳 DS Visual Lab

## 📌 Project Overview

DS Visual Lab is an interactive **Data Structures Visualization Project** developed using **C++**, **HTML**, **CSS**, and **JavaScript**. The project helps students understand complex tree-based data structures through graphical visualizations and simulations.

This project provides implementations and visual demonstrations of advanced data structures including:

* AVL Tree
* Binary Search Tree (BST)
* Red Black Tree
* B Tree
* B+ Tree
* Segment Tree
* Interval Tree
* Quad Tree
* R Tree
* Splay Tree
* Treap

The project consists of a frontend for visualization and a backend implemented in C++.

---

# 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** C++
* **IDE:** Visual Studio Code
* **Compiler:** g++ / MinGW

# 🌲 Data Structures Included

| Data Structure | Description                       |
| -------------- | --------------------------------- |
| AVL Tree       | Self-balancing Binary Search Tree |
| BST            | Binary Search Tree                |
| Red Black Tree | Balanced Binary Search Tree       |
| B Tree         | Multiway Search Tree              |
| B+ Tree        | Advanced Indexed Tree Structure   |
| Segment Tree   | Range Query Data Structure        |
| Interval Tree  | Interval Searching Structure      |
| Quad Tree      | Spatial Partitioning Tree         |
| R Tree         | Spatial Access Method Tree        |
| Splay Tree     | Self-adjusting Binary Search Tree |
| Treap          | Randomized Balanced Tree          |
